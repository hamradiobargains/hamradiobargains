About the Icom IC-7200

The Icom IC-7200 is a 100-watt HF plus 6-meter transceiver (25 watts on AM) launched in 2009 and sold as the rugged one in Icom's lineup — the front panel is water-resistant (not waterproof), the boards live in O-ring-sealed compartments, and the die-cast frame shrugs off field use. It receives 30 kHz to 60 MHz and offers SSB, CW, RTTY, and AM — but no FM, and no internal antenna tuner. The signature feature is the single USB cable that carries both CAT control and audio, making digital modes a one-cable affair, plus digital IF filtering with 51 selectable passband widths and twin PBT — Icom's pitch was "optional filters will never be required." It suits field and portable operators, EMCOMM volunteers, and anyone running digital modes from a laptop — owners routinely call it built like a tank and rate it 4.8/5 across 235+ eHam reviews. The shorthand in owner circles: the 7200 is the Jeep Wrangler outdoor radio to the IC-7300's better indoor radio. Plenty of owners keep theirs as dedicated field rigs after upgrading. When buying used: the single most repeated complaint is the weak stock hand mic — it struggles to modulate fully on SSB, so check drive and audio on transmit; the HM-219 is the common upgrade. Very early serial numbers had factory A and B mods done under warranty, so it's worth asking the seller about serial number and history. The classic owner headache is USB digital setup (driver install, DATA mode enabled in the rig's quick-set menu, USB modulation input selected with modest level, and the usual Windows audio-device renaming) — know that going in rather than discovering it on Field Day. And know the deal points: no FM means no FM repeaters, and you'll need an external tuner (the 7200 can control LDG units or Icom's AH-4).

Common questions

I can't get CAT control or transmit working on the IC-7200 with WSJT-X — where do I start?

For direct CAT, use the enhanced virtual COM port created by the Icom USB driver (not a second program like HRD), disable "CI-V Transceive Mode" in the rig's menu, set PTT Method to CAT in WSJT-X — and shut down anything else that owns the CAT port, since only one application can have it at a time. That combination fixed the poster's setup.

My IC-7200 keys up on digital modes but puts out nothing — what's the checklist?

In the rig's quick-set mode turn DATA mode ON; in set mode set "Modulation input (data ON)" to USB with USB Mod Level around 20%; in WSJT-X select the IC-7200 rig, PTT Method CAT, Mode Data/Pkt, audio in/out to the "USB Audio CODEC" devices with Windows audio enhancements off — then set drive so there's no ALC movement on transmit.

When I select USB-D my IC-7200 switches to RTTY-R — has anyone figured this out?

Yes: the 7200's USB data mode is a subset addressed by a specific CI-V hex command, and the software's default command set was sending the wrong mode. The in-thread fix was editing the CAT .ini file with a corrected hex string for USB data mode, which the poster confirmed worked.
