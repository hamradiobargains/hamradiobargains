About the Icom IC-7100

The Icom IC-7100 is a versatile, multi-band HF/VHF/UHF amateur radio transceiver with touchscreen control, D-STAR digital support, and robust DSP features, ideal for mobile and base station use.

Common questions

Can I configure the IC-7100 to use FLDIGI?

Yes. You can set up the IC-7100 for use with FLDIGI by downloading the required drivers/software from the FLDIGI website and following the configuration steps provided by Icom's support page. Icom does not endorse the software's performance, but the radio supports the necessary interface.

Why does my IC-7100 not show 100W output in SSB mode?

The IC-7100's 100W rating is Peak Envelope Power (PEP), measured with a strong voice signal. Many wattmeters display average power, which will be lower than PEP because it averages the signal over time. This is normal and does not indicate a problem.

How do I connect the IC-7100 to a computer for logging or control?

You can connect the radio via the supplied control cable and use compatible software (e.g., FLDIGI, Log4fun) to log communications or control functions. Ensure the correct drivers are installed and the radio is set to the correct control mode.
