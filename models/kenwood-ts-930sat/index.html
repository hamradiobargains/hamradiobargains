About the Kenwood TS-930SAT

The Kenwood TS-930SAT is a discontinued, high-performance amateur HF transceiver introduced in the early 1980s, designed for operation on 160m through 10m plus WARC bands. The "SAT" denotes the factory-installed AT-930 internal automatic antenna tuner, making it a self-tuning desktop rig.

Common questions

How do I program frequencies and settings?

Use the MEMORY CH (Memory Channel) Operation feature to store and recall frequencies and settings. Press the MEMORY CH key, select a channel number, and enter the desired frequency. You can also store multiple channels for quick access.

What is the difference between the TS-930S and TS-930SAT?

The "SAT" denotes a later production model with some updates, but the core operation and features are the same as the TS-930S. The main differences are in manufacturing date and minor hardware revisions; the manual covers both.

Can I use it without the AT-930?

Yes, but you must connect an external antenna tuner or match the antenna directly to the transceiver's antenna port. The manual's AT-930 section is optional if your unit lacks the tuner.
