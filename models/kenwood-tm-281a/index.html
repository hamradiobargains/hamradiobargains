About the Kenwood TM-281A

The Kenwood TM-281A is a 2 meter FM mobile transceiver putting out a hefty 65 watts of power. You can program up to 200 memory channels (or 100 when used with names). The display has 6 large alphanumeric characters. This radio has NOAA weather built in with alert tone.

Common questions

What programming software is compatible?

The TM-281A is compatible with MCP-1A (Memory Control Program) software, allowing you to save, edit, and write memory channel data. It works with a USB programming cable (KPG-46U).

What is the operating frequency range?

Transmit (TX): K,M4: 144-148 MHz | K,M2,M3: 136-174 MHz. Receive (RX): M2,M3: 136-174 MHz | M4: 144-148 MHz. All frequencies are within the amateur radio band and guaranteed around 144-148 MHz.

How many memory channels are available?

The TM-281A supports up to 200 memory channels (100 with memory names assigned). Each can store transmit and receive frequencies independently. Memory management can also be performed via PC software.
