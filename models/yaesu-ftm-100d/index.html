About the Yaesu FTM-100D

The Yaesu FTM-100D is a dual-band VHF/UHF amateur radio transceiver designed for both C4FM digital and FM analog communications, introduced in 2010.

Common questions

What is the Yaesu FTM-100D/DR?

The FTM-100DR is a 144/430 MHz dual-band mobile transceiver that supports both C4FM digital and FM analog modes, with 50 W RF output on each band.

What modes can it operate in?

It supports three digital modes (V/D, Voice FR, Data FR) and one analog FM mode. The Automatic Mode Select (AMS) automatically detects the received signal mode.

What memory and storage options are available?

It supports micro-SD card storage for logs, messages, and images, plus internal memory for channels and presets.
