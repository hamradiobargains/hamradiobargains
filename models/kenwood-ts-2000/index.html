About the Kenwood TS-2000

The Kenwood TS-2000 is a versatile all-mode HF/VHF/UHF transceiver with optional 1.2 GHz capability, designed for both base and mobile amateur radio operation.

Common questions

What frequency range can the TS-2000 cover?

The TS-2000 operates from HF (1.8-30 MHz) up to 1.2 GHz (TS-2000X/TS-B2000) and includes the amateur 144 MHz and 430/440 MHz bands with a built-in sub-receiver for those bands.

How do I set up FM repeater operation?

Program the repeater offset (e.g., +600 kHz) using the Offset function, select the repeater mode, and transmit with the correct tone (CTCSS/DCSS) if required.

Can the TS-2000 be used for satellite communication?

Yes - it has an instant satellite comm key and supports Sky Command II+ and DX Packet Cluster Tune for satellite operations.
